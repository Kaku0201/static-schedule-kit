# discord-bot

구글시트 `참여인원저장` 시트의 데이터를 읽어와  
새로 추가된 일정이 있을 때 디스코드 채널로 자동 전송하는 선택형 알림 봇입니다.

이 봇은 `일정 추합 시트` 구글시트와 함께 사용할 수 있도록 만들어졌습니다.

## 주요 기능

- `참여인원저장` 시트 읽기
- 새로 추가된 일정 데이터만 감지
- 5분 간격으로 자동 확인
- 새 일정이 여러 개일 경우 한 번에 묶어서 전송
- 참여 인원을 닉네임 기준으로 표시
- 기존에 보낸 일정은 중복 전송하지 않음

## 사용 전 준비물

봇을 사용하려면 아래 정보가 필요합니다.

- 디스코드 봇 토큰
- 디스코드 채널 ID
- 구글시트 ID
- 실행 환경

## 설정 방법

### 1. 디스코드 봇 만들기

1. 디스코드 개발자 포털에 들어갑니다.
2. 새 애플리케이션을 만듭니다.
3. `Bot` 메뉴에서 봇을 생성합니다.
4. 생성된 봇의 토큰을 복사합니다.
5. 봇을 사용할 서버에 초대합니다.

### 2. 디스코드 채널 ID 확인하기

1. 디스코드 설정에서 개발자 모드를 켭니다.
2. 메시지를 보낼 채널을 우클릭합니다.
3. `채널 ID 복사`를 선택합니다.

### 3. 구글시트 ID 확인하기

사용 중인 구글시트 주소에서 시트 ID를 복사합니다.

예시:
```
   text
https://docs.google.com/spreadsheets/d/여기가시트ID/edit
```

### 4. 코드 다운로드

이 레포의 코드를 직접 다운로드하거나 복사합니다.

### 5. 설정값 준비

사용 전 아래 정보를 준비합니다.

- 디스코드 봇 토큰
- 디스코드 채널 ID
- 구글시트 ID
- 확인 주기

### 6. GitHub Actions 설정

이 도구는 GitHub Actions를 이용해 일정 간격으로 자동 실행하는 방식으로 사용합니다.

사용하려면 아래 설정이 필요합니다.

- GitHub 저장소 생성 또는 포크
- GitHub Actions 활성화
- 필요한 환경 변수 또는 시크릿 등록

### 7. 실행

설정이 끝나면 GitHub Actions가 일정 간격으로 자동 실행됩니다.  
도구는 구글시트를 확인하고, 새로 추가된 일정이 있으면 디스코드 채널에 전송합니다.

## 작동 방식

1. 구글시트에서 일정 확정 시간을 입력합니다.
2. 시트의 `참여인원저장` 시트에 날짜, 요일, 시간, 참여 인원이 저장됩니다.
3. GitHub Actions가 일정 간격으로 시트를 확인합니다.
4. 이전에 보내지 않은 새 일정이 있으면 디스코드 채널로 전송합니다.

## 주의사항

- 이 폴더의 코드는 기본 시트 사용에 필수가 아닙니다.
- 디스코드 알림이 필요한 경우에만 설정해서 사용하면 됩니다.
- 깃허브에 있는 코드만으로 바로 자동 실행되지는 않습니다.
- 사용하려면 자신의 GitHub 저장소에서 Actions를 설정해야 합니다.

## 파일 구성

- `requirements.txt` : 필요한 라이브러리 목록
- `.env.example` : 설정값 예시
- `README.md` : 사용 안내 문서
