# static-schedule-kit

공대 일정 추합용 구글시트 템플릿과 선택형 디스코드 알림 도구입니다.

## 구성
- 구글시트 일정 추합 템플릿
- 날짜별 메모 저장 구조
- 참여인원 저장 시트
- 선택형 디스코드 알림 봇 코드

## 사용 대상
- 주간 공대 일정을 정리하고 싶은 사람
- 구글시트로 참여 가능 시간대를 추합하고 싶은 사람
- 필요할 경우 디스코드 알림까지 연동하고 싶은 사람

## 사용 방법
### 1. 구글시트 템플릿 사용
시트를 사본으로 복사해서 바로 사용할 수 있습니다.

### 2. 디스코드 알림 기능
디스코드 알림은 선택 사항입니다.  
필요한 경우 별도 봇 코드를 설정해서 사용할 수 있습니다.

## 주의사항
- 디스코드 알림 기능은 기본 시트 사용에 필수가 아닙니다.
- 배포용 시트는 단독으로도 사용할 수 있도록 구성되어 있습니다.
